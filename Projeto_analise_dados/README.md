# O que é o projeto:
O trabalho se dá pela análise de uma ampla base de dados para descobrir sutis indicativos de uma loja fictícia de varejo. 

## Observações:
O projeto se apresenta em estado inicial e amador, o que pode evidenciar erros ou inconsistências em determinadas ações. O proprietário do conteúdo está disposto a receber correções.
